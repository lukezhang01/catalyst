**Team:** catalyst
**Written:** before sprint work began (see this file's commit date)

**Scope note:** This sprint, interviews run through a browser interview link instead of phone calls (phone calling via Twilio is deferred cuz we had limited time working on this project. Cuz we just pivoted from Evidence Lender to the diligence agent last week because the old one involves too many security and privacy issue).

** Notes for ourself: **sprint** is a development period, usually 1-2 weeks.

## Hypothesis

With the evidence scorecard, users decide whether each thesis claim is supported **at least 50% faster** than reading interview transcripts manually, and reach the same verdict.

**Baseline (manual):** reading 5 interview transcripts and judging 3 thesis claims takes **20 minutes**.

## Kill Metric

If fewer than **70% of testers (n ≥ 2)** finish in under half the baseline time **and** match the manual verdict on all 3 claims, we pivot.

## Trigger Date

**[2026-11-05]**

## Fallback Options

1. **Less automation, same problem:** AI only groups transcript quotes by claim; the user decides the verdict.
2. **Different part of the workflow:** focus on interview planning (which claims need more evidence and who to interview next) instead of synthesis.
